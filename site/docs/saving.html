Copy, save and files

Copy

Copy puts the image on the clipboard so you can paste it straight into a chat, document or email. It also saves the image to your default folder automatically, so nothing is lost.

Save

Save opens a dialog where you choose the file name, folder and format. Tick Always save here to make that folder your default.

Where files go

If you have not chosen a folder, captures go to Pictures\Snapricot. If your chosen folder is not available (for example an unplugged drive), Snapricot suggests a fallback folder instead of failing.

Names and formats

  • Files are named by date and time, for example 2026-10-09_16-07-18.png.
  • Snapricot never overwrites an existing file.
  • Choose PNG (lossless) or JPG (smaller) in Settings.

After saving

Optionally open the containing folder after each save, and choose whether a notification and sound confirm the capture. See Settings.
