Hotkeys

Hotkeys work globally, from any app. Snapricot uses Print Screen combinations so it does not override common shortcuts such as Save As.

ActionDefaultLaptop alternative
Capture custom areaCtrl+PrtScCtrl+Shift+1
Capture active windowAlt+PrtScCtrl+Shift+2
Capture full screenShift+PrtScCtrl+Shift+3

Change a hotkey

  1. Open Settings and choose the Hotkeys tab.
  2. Select the action, then press the combination you want.
  3. If another Snapricot action already uses it, you will see a conflict warning. Choose another combination, or use Reset to restore the default.

If a hotkey does not work

  • Another app owns it. If a hotkey is already taken by another program, Snapricot skips it and keeps running. Rebind it to a free combination.
  • Windows opens the Snipping Tool. Windows 11 can send Print Screen to its own screen capture. Use the laptop alternatives, or turn off Use the Print screen key to open screen capture in Windows Settings, Accessibility, Keyboard.
  • No Print Screen key. Many laptops need Fn for it. The Ctrl+Shift+number alternatives avoid that.
