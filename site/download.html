Download Snapricot

Early preview for Windows. It is free, and the whole thing is open source.

Windows 10 / 11 (64-bit)

Get the latest Snapricot-<version>-win-x64.zip from the Releases page. Versions marked Pre-release are early previews.

Go to the Releases page

Install

  1. Download the .zip file from the latest release (under Assets).
  2. Right-click the zip and choose Extract All.
  3. Open the extracted folder and run Snapricot.exe. There is no installer yet, so keep the folder somewhere permanent.

Windows shows "Windows protected your PC"

This is expected. Snapricot is not code-signed yet, and Windows SmartScreen warns about new, unsigned apps. Click More info, then Run anyway.

Code signing is planned and will remove the warning over time. Meanwhile you can verify your download:

Get-FileHash .\Snapricot-<version>-win-x64.zip -Algorithm SHA256

Compare the result with the contents of the .sha256 file on the same release. If they match, the file is the one we published. You can also build it yourself from source.

Requirements

  • Windows 10 (version 2004 or later) or Windows 11, 64-bit
  • About 16 MB of disk space

Build from source

Requires the .NET 10 SDK.

git clone https://github.com/waqasahmaddev/snapricot.git
cd snapricot
dotnet run --project src/Snapricot.App

Uninstall

Turn off Start with Windows in Settings first if you enabled it, then delete the folder. Settings live in %APPDATA%\Snapricot; delete that too for a clean removal.
