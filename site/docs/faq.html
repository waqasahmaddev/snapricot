FAQ

Why does Windows say "Windows protected your PC"?

Snapricot is not code-signed yet, so SmartScreen does not recognise it. Click More info, then Run anyway. You can verify your download with the SHA-256 checksum on the release page, or build it from source.

Is Snapricot free?

Yes. It is open source under the MIT licence, with no ads and no account.

Does it collect data?

No. There is no telemetry and no account. Captures stay on your computer unless you share them yourself.

Can I annotate screenshots?

Not yet. The annotation editor (arrows, text, blur, crop and more) is planned after the History page.

Does it work on macOS or Linux?

Not yet. Windows comes first. The code is structured so a macOS version can follow.

Which Windows versions work?

Windows 10 (version 2004 or later) and Windows 11, 64-bit.

A hotkey does nothing.

Another program may own it, or Windows 11 may be routing Print Screen to the Snipping Tool. See Hotkeys.

How do I report a bug or suggest a feature?

Open an issue on GitHub. Include your Windows version and what you pressed.

How do I uninstall it?

Turn off Start with Windows in Settings, then delete the folder. Remove %APPDATA%\Snapricot to delete settings.
