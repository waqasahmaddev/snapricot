Features

What Snapricot does today, and what is on the way. Features marked Next, Planned or Later are not in the current download.

Available now

In the early preview for Windows.

Custom area capture

Drag a rectangle, then adjust it until it is exactly right.

  • Eight resize handles and move
  • Nudge with the keyboard
  • Type an exact width and height
  • Aspect-ratio presets and lock
  • Light toolbar: Save, Copy, Cancel

Active window and full screen

Capture the window you are in, or the whole screen, with a single hotkey.

Frozen, pixel-exact overlay

The screen freezes before you select, so moving content cannot spoil the shot. The overlay appears on every display. The app hides itself when you start a capture from its window.

Copy and Save

Copy sends the image to the clipboard and saves it to your default folder. Save opens a dialog for the name and folder, with an Always save here option.

  • PNG or JPG
  • Never overwrites an existing file
  • Optional: open the folder after saving

Notifications and sound

A small notification confirms each capture, with an optional shutter sound. Choose bottom right, bottom left, top right, or top left.

Global hotkeys

Capture from any app with Print Screen combinations, plus laptop-friendly alternatives. Record a new combination in Settings; Snapricot warns you about conflicts.

Home screen with recent captures

Capture tiles show their live shortcuts, and a Recent strip shows your twelve newest captures.

Tray and start with Windows

Runs quietly in the system tray. Optionally start with Windows, opening straight to the tray.

On the roadmap

Order and timing can change. Follow progress on GitHub.

Principles

Fast

Native AOT build. Targets: under 300 ms startup, under 60 MB idle memory, under 100 ms from hotkey to overlay.

Private

No account and no telemetry. Settings are one JSON file on your PC.

Open

MIT licensed. Read the code, report a bug, or contribute on GitHub.
